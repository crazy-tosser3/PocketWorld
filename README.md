Мод для Minecraft Forge 1.20.1 (Forge 47.4.x). Добавляет бутылки с личными карманными измерениями: каждая бутылка открывает свой парящий остров, который можно настраивать, обживать и открывать друзьям.

## Возможности

- **Личные острова.** Каждая бутылка создаёт отдельный остров в общем измерении `pocketworld:pocket`. Острова разнесены на 2048 блоков друг от друга.
- **Настройка острова**: местность (холмы, равнина, гора, острова), размер (малый, средний, большой, огромный) и 16 биомов, включая болота. Биом влияет на поверхность, деревья и цвет травы.
- **Небо**: сумерки, закат, день, ночь, северное сияние (звёзды, две луны, плавная смена цветов).
- **Погода**: ясно, дождь, гроза, у каждого острова своя. Она только визуальная: огонь не гасит, молнии безвредны.
- **Животные**: корова, овца, свинья, курица, лошадь, кролик, лиса, волк. Покупаются в конфигураторе за осколки разлома (не больше 12 на острове).
- **Приглашения**: владелец зовёт друзей по клику или командой, у приглашённого в чате появляется кнопка «Войти».
- **Постройки не пропадают.** При смене настроек остров перестраивается, но блоки игроков остаются на месте, а рельеф вокруг подстраивается под них.
- **Безопасность**: в измерении не появляются враждебные мобы, игрок не может упасть в пустоту или уйти за остров.

## Как играть

### Крафт

| Предмет | Рецепт |
|---|---|
| Осколок разлома (2 шт.) | аметистовый осколок + жемчуг Края (без формы) |
| Пустая бутылка | стеклянная бутылка + осколок разлома |
| Бутылка измерения | пустая бутылка + 3 осколка разлома + око Края |
| Конфигуратор | `ИРИ / РЕР / ИИИ`: И железный слиток, Р осколок разлома, Е око Края |

Всё есть и во вкладке творческого режима **Pocket World**.

### Первые шаги

1. Возьмите бутылку и нажмите ПКМ: вы окажетесь на новом острове и станете его владельцем. Бутылка запомнит это измерение.
2. Вернуться: ПКМ бутылкой ещё раз или ПКМ по светящемуся блоку выхода в центре острова.
3. Бутылка служит ключом: войти может любой, у кого она в руках.

### Конфигуратор

ПКМ по блоку открывает окно с бутылкой в слоте и пятью вкладками:

- **Остров**: местность, размер, кнопка «Применить изменения».
- **Биом**: 16 вариантов сеткой.
- **Небо**: тема неба и погода.
- **Звери**: клик по животному покупает его.
- **Гости**: слева приглашённые (клик убирает), справа игроки онлайн (клик приглашает).

Выбранный вариант подсвечен зелёным. Изменения острова (местность, биом, размер) применяются кнопкой «Применить изменения». Небо и погода меняются сразу.

Менять настройки может только владелец (или оператор), и только снаружи: внутри карманного измерения конфигуратор и команды настроек не работают.

### Приглашения

- ПКМ бутылкой по игроку приглашает его.
- Приглашённый нажимает **[Войти]** в чате или использует `/pocket list`.

### Команды `/pocket`

| Команда | Что делает |
|---|---|
| `invite <игрок>` | пригласить |
| `uninvite <имя>` | убрать гостя (выгоняет, если он на острове) |
| `visit <uuid>` | войти по приглашению |
| `leave` | выйти из измерения |
| `list` | свои и чужие острова с кликабельным входом |
| `terrain <тип>` | `normal`, `flat`, `mountains`, `islands` |
| `biome <биом>` | любой биом, например `minecraft:cherry_grove` |
| `size <размер>` | `small`, `medium`, `large`, `huge` |
| `sky <тема>` | `twilight`, `sunset`, `day`, `night`, `aurora` |
| `weather <тип>` | `clear`, `rain`, `thunder` |
| `regenerate` | применить изменения, не ломая постройки |

Настройки (`terrain`, `biome`, `size`, `sky`, `weather`, `regenerate`) действуют на остров из бутылки в руке и работают только вне карманного измерения.

## Сборка

Нужны JDK 17 и Gradle (в проекте есть `gradlew`).

```bash
./gradlew build
```

Готовый мод появится здесь:

```
build/libs/examplemod-1.0.0.jar
```

Имя файла берётся из `mod_id` и `mod_version` в `gradle.properties`. Сейчас там `mod_id=examplemod`, поэтому и jar называется `examplemod`. Если поменять `mod_id` на `pocketworld`, получится `pocketworld-1.0.0.jar`. Идентификатор мода в `mods.toml` при этом уже `pocketworld`.

Установка: положите jar в папку `mods` клиента и сервера (мод нужен на обеих сторонах) с Forge 1.20.1 версии 47.4.28 или новее.

## Запуск для разработки

```bash
./gradlew runClient
./gradlew runServer
```

Если запуск падает с ошибкой «mods.toml missing metadata for modid examplemod», приведите `mod_id` в `gradle.properties` в соответствие с `mods.toml` (`pocketworld`) и обновите конфигурации запуска в IDE.

## Ограничения

- Время суток в измерении фиксировано как день, поэтому небо «ночь» только выглядит ночью.
- Погода рисуется на клиенте для каждого острова отдельно, на геймплей она не влияет.
- Блоки, которые сами изменились после генерации (например, разросшаяся трава), считаются постройками и остаются при перестройке.

## Структура проекта

- `dimension/` — острова, генерация, вход и выход, приглашения, покупка животных.
- `storage/` — сохранение данных измерений в мире.
- `command/` — команды `/pocket`.
- `network/` — пакеты окна конфигуратора и синхронизации неба и погоды.
- `client/` — окно конфигуратора, небо и клиентская погода.
- `src/main/resources/data/pocketworld/` — тип измерения, рецепты, добыча блоков.
